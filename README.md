# 🥬 Aaku Quest
Track buying & eating leafy greens (aaku kuralu). Earn 🪙 coins, level up, collect 🏅 badges, keep your 🔥 streak.

## Install (Mac, macOS 13+, needs Xcode Command Line Tools)
```
mv ~/Downloads/AakuQuest.zip ~/workspace && cd ~/workspace && unzip AakuQuest.zip && cd AakuQuest
./setup.sh
```
Builds the app, installs to /Applications, adds a Desktop shortcut, and creates a public GitHub repo (`gh auth login` once if needed).

Coins: buy katta +10 each · eat +5 · streak +2/day · goal week +25.
Data: ~/Library/Application Support/AakuQuest/entries.json
Website later: put a page in `docs/` and enable GitHub Pages.
